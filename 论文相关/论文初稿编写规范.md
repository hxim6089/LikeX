# 计算机与通信学院本科毕业设计（论文）初稿编写规范

> 依据《计通学院毕业设计（论文）规范化要求（修改版）》及《设计说明书参考模板》综合整理

---

## 一、总体字数要求

| 材料类型 | 最低字数要求 |
|----------|-------------|
| 论文 | 不少于 **2 万字** |
| 设计说明书 | 不少于 **1.5 万字** |
| 外文文献翻译稿 | 不少于 **1.5 万字符**（单独一篇） |

---

## 二、论文结构与装订顺序

论文须独立装订成册，各部分**严格按以下顺序排列**：

1. 封面、扉页
2. 中文摘要、关键词
3. 英文摘要、关键词
4. 目录（含页码）
5. 论文正文
6. 参考文献
7. 外文翻译（原文 + 译文）
8. 致谢
9. 封底

---

## 三、各部分内容要求

### 3.1 封面与扉页

封面和扉页单面打印，须填写以下信息：

- 论文题目（中文）
- 论文题目（英文）
- 学生姓名（中文 + 拼音）
- 学号
- 专业班级
- 指导教师
- 学院：计算机与通信学院
- 答辩日期

### 3.2 中文摘要

- 字数：**不少于 200 字**
- 内容应涵盖：选题背景及意义、主要研究内容、实验方法、本人主要完成的成果
- 语言精炼、准确，深入浅出，通俗易懂
- **关键词**：3～5 个，从题目和正文中挑选最能表达主要内容的词汇，关键词之间用**分号**分隔，最后一个关键词后**不加标点**

### 3.3 英文摘要

- 内容与中文摘要**一一对应**
- 符合英语语法，语句通顺，文字流畅
- **Key Words**：与中文关键词对应，格式同中文关键词要求

### 3.4 目录

- 将文内章节标题依次排列，最多列至**三级标题**
- 标题简明扼要，目录中注明对应页码
- 需包含：摘要、Abstract、各章节、参考文献、外文翻译、致谢

### 3.5 论文正文

正文是论文主体，一般由以下部分构成：

- **引言**（第1章）：研究背景、意义、目的、开发技术介绍等
- **理论分析 / 系统分析**（第2章起）
- **设计过程 / 核心内容章节**
- **计算方法、实验与测试方法**
- **实验结果分析及讨论**
- **设计总结 / 结论**

> 写作形式可因工程设计或科研项目性质不同而变化，但内容应层次分明，结构严谨，论证正确，实验数据可靠。

### 3.6 参考文献

- 按论文中**引用出现的先后顺序**列出，置于正文末尾
- 数量一般在 **20 篇以上**，其中**外文资料不少于 2 篇**
- 引用他人成果时，必须在引用处加以注明，避免抄袭
- 作者不超过三位时全部列出；超过三位只列前三位，后加"等"或"et al."
- 作者姓名之间用逗号分开；外文作者姓前名后，名用缩写，不加缩写点

**各类文献著录格式：**

```
期刊：
[序号] 作者. 题名[J]. 刊名，出版年份，卷号(期号): 起止页码

专著：
[序号] 作者. 书名[M]. 版本(第1版不标注). 出版地: 出版社，出版年. 起止页码

论文集：
[序号] 作者. 题名[A]. 见: 主编. 论文集名[C]. 出版地: 出版者，出版年. 起止页码

学位论文：
[序号] 作者. 题名[D]. 保存地点: 保存单位，年份

专利：
[序号] 专利申请者. 题名[P]，国别，专利文献种类，专利号. 出版日期

电子文献：
[序号] 作者. 题名[DB/CP/EB]. 文献出处. 发表或更新日期/引用日期
```

**参考文献示例：**

```
[1] Schaafstal A M, Johnston J H, Oser R L. Training teams for emergency management[J].
    Computers in Human Behavior, 2001, 17(5-6): 615-626.

[2] 熊山, 郭建龙, 祁彦威, 等. 基于多人协同虚拟现实的主变应急培训应用研究[J].
    计算技术与自动化, 2021, 40(04): 145-150.

[3] 白晓芳. 基于ASP.net的商品评论系统的设计与实现[D]. 东北大学, 2015.

[4] Copeland L. A practitioner's guide to software test design[M]. Artech House, 2004.
```

### 3.7 外文翻译

- 包括**原文**和**译文**两部分，均作为二级标题
- 译文字符数不少于 **1.5 万字符**

### 3.8 致谢

- 对给予资助、指导和协助完成研究工作的单位及个人表示感谢
- 应实事求是，**切忌浮夸与庸俗之词**

---

## 四、撰写规范

1. **书写要求**：一律用标准 A4 纸打字成文
2. **文字要求**：文字通顺，语言流畅，无错别字
3. **图表要求**：所有曲线、图表、流程图、程序框图、示意图等**不得徒手画**，必须按国家规定标准或工程要求绘制，且图表须在正文中引用

---

## 五、打印格式规范

### 5.1 页面设置

| 项目 | 设置值 |
|------|--------|
| 纸张 | 标准 A4 |
| 行间距 | 22 磅 |
| 首行缩进 | 2 字符 |
| 上边距 | 2.5 cm |
| 下边距 | 2.5 cm |
| 左边距 | 2.5 cm |
| 右边距 | 2.0 cm |
| 页眉 | 1.5 cm |
| 页脚 | 1.75 cm |

**页码规则：**

| 区域 | 页码格式 | 起始编号 |
|------|----------|----------|
| 摘要页 | Ⅰ、Ⅱ | Ⅰ |
| 目录 | 阿拉伯数字 | 1 |
| 正文 | 阿拉伯数字 | 1 |

页码字号：小5号，居中排列。

### 5.3 图的规范

- 图号按**章顺序编号**，格式：`图X-Y`（X为章号，Y为该章第几个图，如"图3-2"）
- 图题采用五号楷体，居中，置于图**下方**
- 引用图应在图题右上角标出文献来源
- 绘图必须工整、清晰、规范
- 示意图应清楚反映图示内容
- 照片应在下方给出放大标尺
- 实验结果曲线图应制成**方框图**

### 5.4 表格的规范

- 表格按**章顺序编号**，格式：`表X-Y`（如"表5-4"）
- 每个表格必须有标题，采用五号楷体，置于表**上方**
- 表内必须按规定符号标注单位
- 表内同一栏数字必须**上下对齐**

### 5.5 公式的规范

- 公式另起一行书写，较长公式另行居中横排
- 公式编号按**章顺序编排**，标注于该行**最右边**，格式：`（X-Y）`（如"（3-2）"）
- 必须转行时，只能在 **＋、－、×、÷** 处转行
- 上下式尽可能在**等号处对齐**

---

## 六、参考文献引用格式

- 按引用出现顺序用阿拉伯数字连续编号，置于**方括号**内
- 视情况作为**上标**或作为**论文组成部分**引用

引用示例：
```
……李××[1]对此作了研究，数学模型见文献[2]。
```

## 七、提交与答辩安排

| 时间节点 | 要求 |
|----------|------|
| 答辩前**一周** | 上交全部材料，由指导教师进行答辩资格审查并写出评语 |
| 答辩前**三天** | 指导教师返回全部材料，学生根据意见完成最后修改，准备答辩 |

**答辩内容要求（学生自述 10～15 分钟）：**

1. 课题任务、目的与意义
2. 所采用的原始资料或指导文献
3. 设计（论文）的基本内容及主要方法
4. 设计（论文）的价值
5. 对自己完成任务的评价

**答辩委员会提问（10 分钟）：**

1. 要求进一步说明的问题
2. 课题有关的基本理论、认识、方法和原理
3. 考察学生独立工作能力和创新能力的问题

---

## 八、评分标准

总成绩 = 平时成绩（60分）+ 答辩成绩（40分），按五级制评定：

| 等级 | 分数段 | 主要标准 |
|------|--------|---------|
| **优秀** | 90～100 | 圆满完成任务，熟练综合运用理论，立论正确，有独到见解；说明书条理清楚，文字通顺；答辩思路清晰，主要问题回答正确深入 |
| **良好** | 80～89 | 较好完成任务，立论正确，有一定水平；说明书论述正确，图纸完备整洁；答辩论点基本正确，主要问题能正确回答 |
| **中等** | 70～79 | 基本完成任务，非主要内容有欠缺；说明书有个别错误或表达不清；答辩主要问题回答基本正确，但分析不够深入 |
| **及格** | 60～69 | 在指导下按期完成，独立工作能力较差；说明书论述不够恰当，图纸有个别明显错误；答辩主要问题经启发后能答出，回答较肤浅 |
| **不及格** | 60以下 | 未按期完成，基本概念未掌握，原则性错误较多；说明书质量很差；答辩阐述不清，基本概念糊涂 |
